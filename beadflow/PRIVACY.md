## 3. 我们处理哪些信息

| ------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------- | -------------------------- |
| 账号信息           | 邮箱、Supabase 用户标识、邮箱确认状态                                                      | 注册、登录、找回密码、识别数据归属       | 是                         |
| 认证与安全信息     | 登录会话、访问令牌、认证请求时间，以及服务商为安全运行可能处理的 IP 地址、浏览器或设备信息 | 保持登录、阻止未授权访问、限流和安全排查 | 是                         |

| 图纸内容           | 每个格子的行列、MARD 色号或空白状态、制作状态、不可变版本号                                | 编辑、保存、恢复和校验拼豆图纸           | 是                         |

密码由 Supabase Auth 直接处理。BeadFlow 业务数据库不保存可读明文密码。请勿在项目名称或图纸内容中填写身份证号、金融账户、健康信息等与拼豆制作无关的敏感个人信息。

## 4. 处理目的与依据

我们在实现以下目的所必要的范围内处理个人信息：

1. 创建并维护账号，提供登录、邮箱确认和密码恢复；
2. 创建、保存、读取和恢复归属于当前用户的项目及图纸版本；
3. 校验结构化材料仅使用有效 MARD 色号并满足版本一致性；
4. 防止越权访问、滥用和版本覆盖，记录必要的审计信息；
5. 响应个人信息权利请求并履行适用的法律义务。

账号、项目和图纸信息主要用于履行用户主动请求的服务；依法需要同意或单独同意的处理，我们将在处理前另行取得。

## 5. 本地存储、Cookie 与导出

为了维持登录状态，Supabase 客户端会在浏览器中保存必要的认证会话。我们目前不使用营销 Cookie。

用户主动导出的 JSON、CSV、PNG 和 PDF 文件由浏览器在本地生成并下载。除非用户随后主动上传或分享，BeadFlow 不会自动取得这些导出文件。

## 6. 委托处理与境外存储

BeadFlow 当前使用 Supabase 提供数据库、认证和 API 服务。项目的主区域为日本东京（AWS `ap-northeast-1`）。因此，中国境内用户的下列信息可能被传输并存储至境外：

- 邮箱、账号标识和认证相关信息；
- 项目名称、描述、画布尺寸和状态；
- 图纸格子、MARD 色号、版本和审计记录；
- 服务安全运行所需的网络与错误信息。

境外受托处理方为 Supabase, Inc. 及其依照数据处理协议使用的获授权子处理者，其中托管服务主要由 Amazon Web Services 提供。处理目的限于提供认证、数据库、API、托管、安全和支持服务。

**发布阻断项：** 面向中国境内用户公开注册前，运营者必须完成个人信息保护影响评估，核实适用的数据出境路径，并在注册前以独立、明确的交互取得个人信息出境单独同意。仅勾选“同意隐私说明”不得替代该步骤。

## 7. 信息共享、转让与公开

除本说明列明的受托处理、履行法律义务或取得用户另行同意外，我们不会向其他个人信息处理者提供个人信息，也不会公开披露个人信息。

如发生合并、分立、资产转让或运营主体变更，我们将依法告知接收方信息，并要求接收方继续履行个人信息保护义务；处理目的或方式发生实质变化时，将依法重新取得同意。

## 8. 保存期限与删除

我们遵循实现处理目的所必要的最短保存期限原则：

- 账号、项目和图纸版本：原则上保存至用户删除账号或请求删除，或服务终止且继续保存不再必要；
- 审计记录：当前用于版本追溯和安全审计，**具体保存期限待产品负责人结合安全与合规需要确认**；
- 认证、安全和服务日志：**具体保存期限待与 Supabase、部署平台及日志配置核对**；
- 备份中的残留数据：在正常备份轮转周期内删除，**具体最长周期待确认**。

法律法规要求继续保存，或删除在技术上暂时难以实现时，我们将停止除存储和采取必要安全保护措施之外的处理。

## 9. 用户的个人信息权利

在适用法律规定的范围内，用户可以请求：

- 撤回基于同意开展的处理；
- 限制或拒绝特定处理；

## 10. 信息安全

我们采取与风险相适应的措施，包括：

- Supabase Auth 身份认证和会话管理；
- PostgreSQL 行级安全策略（RLS），限制用户只能访问自己的项目；
- 服务端尺寸、矩阵、色号和版本校验；
- 数据库事务、不可变图纸版本和写操作审计；
- 发布密钥与服务端密钥分离，不在客户端保存服务端秘密。

任何网络服务都无法保证绝对安全。如发生或可能发生泄露、篡改或丢失，我们将依法采取补救措施，并通过**[待补充通知渠道]**告知受影响用户和主管部门。

## 11. 未成年人

BeadFlow 当前不面向不满 14 周岁的未成年人提供账号服务，也不会主动识别或收集其身份信息。如果运营者未来允许不满 14 周岁的用户注册，必须事先取得监护人同意并制定专门的未成年人个人信息处理规则。

在启用照片上传、相机扫描、库存、制作进度、Agent 或新的第三方服务前，我们将重新核对数据类别、处理目的、保存位置和接收方；如变化对个人权益有重大影响，将在功能启用前更新说明并依法另行取得同意。

我们会在处理目的、方式、信息种类、保存期限、境外接收方或用户权利渠道发生变化时更新本说明。重大变化不会仅以静默替换文本的方式生效。
