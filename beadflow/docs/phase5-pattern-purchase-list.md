# 图纸补豆清单

更新时间：2026-07-22

## 用户流程

1. 用户打开已完成人工确认的图纸资料卡。
2. 系统只读比较正式材料版本与当前个人库存。
3. 仅当存在缺口时显示“生成一键补豆清单”。
4. 清单按缺少数量排序，并展示 MARD 色号、需要数量、现有数量、需补数量和库存可信度。
5. 用户可以复制纯文本或下载带 UTF-8 BOM 的 CSV，便于在中文表格软件中打开。

## 可靠性边界

- 只使用已确认的不可变材料版本，OCR 草稿不能生成清单。
- 生成、复制和下载均不会扣减、预留或修改库存。
- 估算库存明确标记，补豆前提醒用户复核。
- API 或复制失败时保留当前页面与材料结果，可直接重试或手工复制。
- 清单由后端统一生成，网页不重复实现缺口计算规则。

## 验证场景

- 真实 54×54、2136 颗图纸库存充足时不显示补豆入口。
- 三个色号同时缺豆，分别覆盖准确库存和估算库存。
- 清单按缺口排序，合计 118 颗，并生成三组色系。
- 复制文本成功后给出明确反馈。
- API 请求全部为 GET，没有任何库存写入。
