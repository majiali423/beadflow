# 图纸库存对比与补豆清单

更新时间：2026-07-22

## 本阶段目标

用户完成人工复核后，App 才能使用该图纸的正式材料版本与个人库存比较，明确回答：

- 每个色号需要多少、现有多少；
- 哪些颜色够用；
- 哪些颜色缺少以及各缺多少；
- 当前库存是否包含估算数量；
- 可复制或导出的补豆清单。

## 可靠性边界

- 不读取 OCR 草稿，未确认图纸返回 `409 MATERIALS_NOT_CONFIRMED`；
- 不根据图片颜色猜色号，只使用用户确认的 MARD 色号；
- 不自动扣减、预留或修改库存；
- 缺少量始终是 `max(图纸需要量 - 当前库存, 0)`；
- 库存中没有的色号按 0 颗计算；
- 估算库存会在结果和补豆清单中保留提示；
- 色号及 HEX 均来自正式 `mard221.json` 色卡。

## 接口

- `GET /api/pattern-cards/:id/inventory-check`
- `GET /api/pattern-cards/:id/purchase-list`

两者都要求登录，并依赖 Supabase RLS 和所有权校验。采购清单按缺少数量从多到少排序，同时提供分色系结果、复制文本与带 BOM 的 CSV。

## 真实规模测试

使用 21 个色号的正式材料版本进行测试，组合了：

- 常用色数量不足；
- 多个颜色库存充足；
- 三个颜色完全没有库存记录；
- 一个颜色为估算库存；
- 总材料量大于简单演示图纸。

测试验证缺豆汇总、够用/缺少颜色数、采购清单排序、估算库存标记，并断言三个库存写入方法均未被调用。
