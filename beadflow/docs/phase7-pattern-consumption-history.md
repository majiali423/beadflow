# Phase 7：制作与库存变动历史

## 功能

- 图纸库读取最近 20 次制作记录，接口最大允许 50 条。
- 按一次完整制作聚合显示，不把多个色号拆成难以理解的独立流水。
- 显示图纸名称、制作时间、正式材料版本、总颗数和当前状态。
- 状态明确区分“已扣库存”和“已撤销并恢复”，不只依赖颜色。
- 展开后显示逐色用量以及当时扣减后的库存余额。
- 可从历史记录直接打开对应图纸。
- 历史查询只使用已有 RLS 表进行读取，不修改数据库和库存。

## 数据来源

- `pattern_card_consumptions`
- `pattern_card_consumption_items`
- `pattern_cards`

三张表通过已有外键关系由 PostgREST 一次查询，所有表继续受用户级 RLS 保护。

## 验证数据

自动化页面测试使用已撤销的真实规模记录：6 色、2136 颗，其中 B14 为 526 颗、C6 为 617 颗。测试覆盖状态、总量、展开明细和只读请求。
