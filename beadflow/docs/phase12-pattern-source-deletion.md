# Phase 12：图纸原图删除

更新时间：2026-07-22

## 目标

允许用户在材料复核完成后删除私有图纸原图，同时保留仍有实际用途的材料统计、库存变化和制作历史。

## 产品规则

- 只有已确认材料的图纸资料卡可以删除原图，避免用户在复核完成前失去 OCR 证据。
- 删除必须经过两次明确点击，界面提前说明不可恢复的影响。
- 删除的是 `pattern-images` 私有存储中的文件，不删除图纸资料卡。
- 已确认材料版本、补豆计算、库存扣减、撤销和制作历史不受影响。
- 图纸库用“原图已删除”占位块替代失效图片，不生成虚假缩略图。
- 重复请求返回第一次删除时间，不重复修改记录。
- 用户重新主动上传完全相同的原图时，原图状态可以恢复。

## 安全与一致性

1. 数据库准备函数先确认当前用户拥有资料卡，并确认资料卡已完成复核。
2. API 使用用户自己的 Supabase 访问令牌删除其路径下的私有文件。
3. 文件删除成功或已经不存在后，数据库才写入 `source_deleted_at`。
4. 若存储删除失败，不写删除时间，资料卡和库存均不变。
5. Storage 删除策略限定路径第一段必须等于当前用户 ID。
